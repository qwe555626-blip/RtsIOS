# 红色警戒：前线（iOS 迷你 RTS）

一个使用 SwiftUI 绘制的 iPhone 即时战略小游戏原型，灵感来自经典基地建设与坦克对战玩法。所有图形均由代码绘制，不依赖外部素材。

## 在 iPhone 上运行

1. 使用 Xcode 15 或更新版本打开 `Package.swift`。
2. 选择 iPhone 模拟器或连接的 iPhone 作为运行目标。
3. 点击 Run。首次在真机运行时，在 Xcode 中配置你的开发团队和签名。

## 当前玩法

- 点选蓝色坦克或采矿车，再点击战场移动。
- 敌军会自动向我方基地推进，近距离自动交战。
- 坦克花费 300 资金；采矿车花费 200 资金，并定期带来收入。
- 推进到敌方基地附近即可攻击；摧毁敌方基地获胜。
- 点击“重开”重新开始。

这是一个可继续扩展的原型，尚未包含联网、音效、关卡和正式美术素材。
